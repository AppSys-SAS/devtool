# Devtool

A local development environment: one server that runs the commands of your projects in real terminals,
routes their services and shares their environment with your team, driven from a web interface and by
coding agents through its MCP server.

## Install

You need Node.js 24 or later, on macOS or Linux.

```bash
npm install -g @appsys/devtool
devtool --version
```

## Start

```bash
devtool server
```

Open <http://127.0.0.1:6730>, then follow the [getting started guide](https://appsys-sas.github.io/devtool/guide/getting-started) to
describe your projects.
