# Examples

Working code to download, run as is or start from.

## Environment

- [Run a CDN server](/examples/cdn-server): a small server of the devtool files API, for a `cdn` backend.
- [Backend scripts](/examples/backend-scripts): two scripts for a `scripts` backend, a shared folder or any storage rclone reaches.

## Integrations

- [Recommended tools](/examples/dev-tools): databases, a mail catcher, an S3 server and their consoles in one `docker-compose.yml`, shown in the sidebar of the devtool.
